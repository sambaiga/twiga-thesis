# FPQR Ablation v2: Run Guide

Design ablation for the FPQR distribution head on top of the MLPGAM backbone.
Extends v1 (`mlpgamfpqr_ablation.py`) with improved statistical power, novel
proposal losses, and heavy-tailed synthetic datasets.

---

## Quick-start

```bash
# 1. Generate synthetic datasets (one-time, ~5 s)
uv run python experiment/common/synthetic_netload.py

# 2. Smoke-test on SYN-HT3 with 3 folds, 10 epochs
uv run python chapters/ch6_conformal/mlpgamfpqr_ablation.py \
  --dataset SYN-HT3 \
  --group proposal prop_loss \
  --epochs 10 --num-trials 5 --folds 3

# 3. Full run on all four datasets
uv run python chapters/ch6_conformal/mlpgamfpqr_ablation.py \
  --dataset MLVS-PT MLVS-UK SYN-HT3 SYN-HT10
```

---

## Datasets

| Name | Type | Residual | Solar | Kurtosis | Purpose |
|------|------|----------|-------|----------|---------|
| `MLVS-PT` | Real | n/a | 30 min, Madeira | ~6 | Primary real-data benchmark |
| `MLVS-UK` | Real | n/a | 30 min, Plymouth | ~2 | Lighter-tail real-data benchmark |
| `SYN-HT3` | Synthetic | Student-t (df=3) | 30 % | **84** | Extreme heavy-tail ablation |
| `SYN-HT10` | Synthetic | Student-t (df=10) | 50 % | ~0 | Near-Gaussian control |

Synthetic datasets are generated by `experiment/common/synthetic_netload.py` and saved
to `examples/data/`. Both share the same deterministic load/solar skeleton; only
tail severity and solar fraction differ.

## CLI reference

```
usage: mlpgamfpqr_ablation.py [--group GROUP [GROUP ...]]
                            [--dataset DATASET [DATASET ...]]
                            [--skip-hpo]
                            [--epochs N] [--num-trials N] [--folds N]
                            [--tracking-uri URI]
```

| Flag | Default | Description |
|------|---------|-------------|
| `--group` | `all` | Ablation groups to run (space-separated, see table below) |
| `--dataset` | `all` | Datasets to run |
| `--skip-hpo` | off | Reuse existing backbone HPO params; skip Phase 1 |
| `--epochs N` | 100 | Override training epochs (use 10–20 for smoke tests) |
| `--num-trials N` | 50 | Override Optuna HPO trials |
| `--folds N` | 20 | Override number of CV folds |
| `--tracking-uri` | none | MLflow tracking URI (e.g. `sqlite:///mlruns.db`) |

## Ablation groups (60 conditions across 13 groups)

| Group | Conditions | Reference | What it tests |
|-------|-----------|-----------|---------------|
| `proposal` | softmax, horizon, kumaraswamy | softmax | Proposal grid type |
| `prop_loss` | w1, sqda, sqda_kl, combined | prop_loss_w1 | Proposal training loss (W1 vs SQDA) |
| `stop_gradient` | {softmax,kuma} × {sg_on,sg_off} | softmax_sg_on | Pinball gradient through τ-embedding |
| `tau_embed` | TimeEmb, LinearEmb, ConvEmb | time_emb | τ projection head |
| `n_quantiles` | 9, 14, 23, 36, 57, 90 (geometric, ratio≈1.585) | nq_9 | Grid granularity |
| `num_cosines` | 0 (RoPE), 16, 32, 64 | cos_32 | Cosine embedding capacity |
| `rope_type` | linear, tau_pos, factored, direct | rope_linear | RoPE variant (num_cosines=0) |
| `crossing` | λ=0,1,3.16,10,31.6,100 (half-decade log) | cross_10 | Crossing penalty weight |
| `sort_output` | False, True, True+λ=0 | sort_false | Post-hoc differentiable sort |
| `qvn_type` | relu, softplus, monotone, monotone_cal | qvn_relu | Value network architecture |
| `loss_fn` | pinball, huber×3, winkler | pinball | Value network training loss |
| `lambda_cal` | 0.001–0.1 (5 values) | lambda_cal_010 | CALCE weight for monotone_cal QVN |
| `prop_nq` | {softmax,kuma} × {9,23,57} | softmax_nq9 | 2-D proposal × grid size interaction |
| `best_config` | default, best, best_interval | default_config | Assembled winner vs factory defaults |

Run a subset of groups:
```bash
uv run python chapters/ch6_conformal/mlpgamfpqr_ablation.py \
  --dataset SYN-HT3 SYN-HT10 \
  --group proposal prop_loss stop_gradient prop_nq lambda_cal
```

## Output metrics (per forecast day, per fold)

Every condition produces rows tagged with `metric_type ∈ {point, interval, quantile}`.
All three types are recorded for every condition.

### Point metrics (`metric_type = point`)

| Column | Description |
|--------|-------------|
| `mae` | Mean Absolute Error (kW), primary point accuracy |
| `nrmse` | Normalised RMSE (by range), scale-free accuracy |
| `corr` | Pearson correlation, pattern accuracy, bias-independent |
| `nbias` | Normalised bias, signed, reveals systematic over/under-prediction |

### Interval metrics (`metric_type = interval`)

| Column | Description |
|--------|-------------|
| `winkler_score` | Interval score for 90 % PI, penalises width and missed coverage |
| `picp` | Predictive Interval Coverage Probability, nominal target 0.90 |
| `nmpi` | Normalised Mean PI Width, sharpness (lower = sharper) |
| `cwe` | Coverage Width-based Criterion, joint coverage + width score |

### Quantile metrics (`metric_type = quantile`)

| Column | Description |
|--------|-------------|
| `pinball` | Mean pinball loss across all N quantile levels |
| `tail_pinball` | Pinball restricted to τ ∈ {0.05, 0.10, 0.90, 0.95}, tail skill |
| `crps` | Continuous Ranked Probability Score, proper scoring rule |

Additional columns present in every row: `condition`, `group`, `dataset`,
`fold_start`, `fold_end`, `fold_month`, `season`, `Folds`, `Model`,
`inference-time`, `timestamp`.

## CV protocol (v2 vs v1)

| Parameter | v1 | v2 |
|-----------|----|----|
| `cv_folds` | 10 | **20** |
| `cv_test_size` | 4 months | **2 months** |
| Datasets | 2 (PT, UK) | **4 (+ SYN-HT3, SYN-HT10)** |
| Paired observations | 20 | **80** |
| Detectable effect (Winkler) | ~7 units | **~3.5 units** |

---

## Recommended run order

1. **Smoke-test** (< 5 min): `--dataset SYN-HT3 --group proposal --epochs 10 --folds 3`
2. **Key new groups** on synthetic only: `--dataset SYN-HT3 SYN-HT10 --group proposal prop_loss stop_gradient lambda_cal`
3. **Full synthetic run**: `--dataset SYN-HT3 SYN-HT10 --group all`
4. **Full run all datasets**: `--dataset MLVS-PT MLVS-UK SYN-HT3 SYN-HT10 --group all`

For step 3 and 4 on real datasets, use `--skip-hpo` after the first run of each
dataset to avoid re-running the 50-trial Optuna search.

## Results file

Output is written to `experiment/fpqr_ablation_v2_full.csv` (or the path set by
`output_dir` in `PipelineConfig`). Load for analysis:

```python
import pandas as pd

df = pd.read_csv("experiment/fpqr_ablation_v2_full.csv")

# Point metrics per condition
pt = df[df["metric_type"] == "point"]
pt.groupby(["group", "condition"])["mae"].mean()

# Interval metrics per condition per dataset
iv = df[df["metric_type"] == "interval"]
iv.groupby(["group", "condition", "dataset"])["winkler_score"].mean()

# Tail skill on heavy-tailed dataset only
tq = df[(df["metric_type"] == "quantile") & (df["dataset"] == "SYN-HT3")]
tq.groupby(["group", "condition"])["tail_pinball"].mean()
```
